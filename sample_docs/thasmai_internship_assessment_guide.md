# Thasmai Infotech Technical Talent Assessment Guide

## Assigned Project Track & Problem Statement (P07)
- **Track Code:** P07 — AI Document Assistant & Grounded Q&A System
- **Problem Statement:** Candidates must solve the enterprise challenge of untrusted AI responses and document search inefficiency by building a production-grade AI Document Assistant. The system must ingest technical documents, apply hybrid BM25 and vector retrieval, provide strict sentence-level source citations, enforce anti-hallucination confidence guardrails, and implement live evaluator adjustments.
- **Core Goal:** Convert this problem statement into a fully working prototype within the 10-day evaluation timeline.

## Objective and Overview
The Thasmai Infotech 10-Day Project-Building Assignment evaluates a candidate's ability to convert a problem statement into a production-grade working application. Candidates must demonstrate planning, interface development, application logic, data handling, integration, testing, documentation, and the ability to defend their work in a technical viva.

## Evaluation Rubric Breakdown (100 Marks Total)
The candidate is graded across eight distinct areas:
1. Understanding the problem and planning: 10 marks
2. Frontend and user experience: 15 marks
3. Backend and application logic: 15 marks
4. Database and data handling: 10 marks
5. Integration and end-to-end functionality: 20 marks
6. Problem-solving, debugging and adaptability: 10 marks
7. Deployment, code organisation and documentation: 5 marks
8. Technical explanation, live modification and viva: 15 marks

## Minimum Project Expectations
Every submission must include:
- A fully working prototype that solves the selected problem.
- At least three meaningful, demonstrable features.
- A usable interface appropriate to the chosen platform.
- Persistent data storage using a database or structured file storage.
- Input validation and rigorous error handling.
- A clear end-to-end workflow testable by the evaluator.
- Organised source code and setup instructions.

## Day 8 Evaluator Change Request
On Day 8 or during the technical viva, the evaluator asks the candidate to implement one live modification to verify code comprehension and adaptability. Typical modifications include:
- Adding a document or category filter.
- Adjusting similarity confidence thresholds dynamically.
- Exporting query and citation reports to JSON or PDF.
- Preventing duplicate document uploads with checksum hashing.
